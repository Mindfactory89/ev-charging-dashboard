# v1.6.0 – Dein Dashboard, deine E-Garage

## Deutsch

Dieses Release hat mit einer ziemlich einfachen Erkenntnis angefangen: Das Dashboard war über die Zeit doch sehr stark auf meinen CUPRA Born zugeschnitten. Für mich persönlich war das lange okay, für ein offenes Projekt aber irgendwann einfach zu eng.

Deshalb habe ich den Fahrzeugbereich einmal komplett neu gedacht. Aus einem festen Fahrzeugprofil ist eine richtige E-Garage geworden. Es gibt jetzt einen durchsuchbaren Startkatalog mit verschiedenen Marken, eigene Fahrzeugprofile und eine zentrale Fahrzeugauswahl. So kann man entweder ein einzelnes Auto betrachten oder alle Fahrzeuge gemeinsam auswerten.

Was neu dazugekommen ist:

- Eigene Fahrzeuge lassen sich mit Hersteller, Modell, Variante, Modelljahr, Akku, Verbrauch und Ladeleistung anlegen.
- In der persönlichen Installation kann auch ein eigenes Autobild verwendet werden. In der öffentlichen Demo bleibt der Upload zum Schutz des Servers komplett ausgeschaltet.
- Die Fahrzeugauswahl gilt jetzt durchgängig für Übersicht, Analyse, Verlauf, Forecasts und Jahresvergleiche.
- Neue Ladevorgänge bekommen eine stabile Fahrzeugprofil-ID. Bestehende Daten funktionieren trotzdem weiter und müssen nicht neu angelegt werden.
- Das Onboarding wurde erweitert, damit das Standardfahrzeug direkt beim ersten Start festgelegt werden kann.
- Import, Export und Telegram sind nicht mehr auf ein bestimmtes Fahrzeug zugeschnitten.

Neben der E-Garage ist auch im restlichen Dashboard einiges passiert: persönliche Ziele und Ladeprofile, ein priorisierter Aktionsplan, bessere Datenqualitätsprüfungen, Benachrichtigungen, lokale Sicherungen, eine installierbare PWA und der Schnellzugriff per Tastatur. Gerade im Alltag machen diese kleineren Dinge für mich einen großen Unterschied.

Unterm Strich ist das Dashboard damit deutlich offener und persönlicher geworden. Der CUPRA Born ist natürlich weiterhin dabei – aber eben als eines von vielen möglichen Fahrzeugen.

## English

This release started with a fairly simple realisation: over time, the dashboard had become very closely tied to my own CUPRA Born. That worked well for me, but it eventually felt too narrow for an open project.

So I rebuilt the vehicle side of the dashboard. A fixed vehicle profile has turned into a proper EV garage with a searchable starter catalogue, custom vehicles, and one central vehicle selector. You can now focus on a single car or look at the complete fleet together.

What is new:

- Custom vehicles can include the manufacturer, model, variant, model year, battery, consumption, and charging power.
- Personal installations can use their own vehicle image. Uploads stay completely disabled in the public demo to protect the server.
- The selected vehicle now carries through the overview, analysis, history, forecasts, and year comparisons.
- New charging sessions use a stable vehicle-profile ID. Existing data remains compatible and does not need to be recreated.
- The onboarding flow now lets you choose the default vehicle right from the start.
- Import, export, and Telegram are no longer built around one particular car.

There has also been quite a bit of work outside the garage: personal goals and charging profiles, a prioritised action plan, stronger data-quality checks, notifications, local backups, an installable PWA, and keyboard quick access. These are not always the loudest features, but they make a real difference when using the dashboard every day.

Overall, the dashboard feels much more open and personal now. The CUPRA Born is still there, of course – it is simply one of many possible vehicles instead of the centre of everything.
